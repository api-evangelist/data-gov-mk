# data.gov.mk (data-gov-mk)

data.gov.mk is North Macedonia's national government open-data portal, operated by the Ministry of Digital Transformation, running **CKAN** over ~280+ datasets from 50+ public institutions.

**URL:** [Visit APIs.json URL](https://raw.githubusercontent.com/api-evangelist/data-gov-mk/refs/heads/main/apis.yml)

## Type
- **kind:** government  ·  **software:** CKAN

## API
- **data.gov.mk CKAN Action API** — base `https://data.gov.mk/api/3/action`. [Docs](https://docs.ckan.org/en/latest/api/) · [Portal](https://data.gov.mk/)
- Standard CKAN actions: `package_search`, `package_list`, `status_show`. DCAT exports: N3, TTL, XML, JSON-LD.
- **Note:** the host was unreachable from this environment (connection timeout / HTTP 000), most likely a geographic/IP firewall block rather than an outage — it is indexed and described as live by the Ministry and the Dateno registry. Platform/endpoints are documented but the live JSON response was not confirmed from automated probes.
